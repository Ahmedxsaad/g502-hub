Lighting that watches with you

Effects saved on the mouse work anywhere. Live effects run from the tray and react to what's happening.

  • Screen sampler for films, videos and games, per zone: the whole screen, the center, or an edge.
  • Audio visualizer in pulse, spectrum or rainbow-beat style, from whatever is playing.
  • Color wave and DPI colors, so you always see which level you're on.
  • Fixed, breathing and color cycle stored in the mouse, with a color wheel and your own saved colors.
Sensitivity

DPI you can feel

Drag a level on the track and the sensor follows while you drag.

  • Five levels from 100 to 25,600 in 50-DPI steps, with a default and a sniper level.
  • Report rate from 125 to 1000 Hz.
  • An on-screen popup shows the new DPI when you press G7 or G8.
Assignments

Eleven buttons, two layers

Hold G-Shift and every button does something else.

  • Any key combination, labelled for your keyboard layout: QWERTY, AZERTY, QWERTZ and the rest.
  • Mouse buttons, scrolling, DPI and profile controls, and media keys.
  • Macros recorded or built step by step: saved on the mouse, or run by the app to type text and repeat while held.
  • Everything is stored in the mouse, so it works on any computer.
Profiles

Five setups that live in the mouse

G9 switches between them, with or without the app.

  • Export a profile to a file and share it; import someone else's into any slot.
  • Rename, reorder the G9 cycle, copy, or reset a slot to factory.
  • A full backup of the mouse's memory before the first change of every session.

PROTON · EXPERIMENTAL

LIGHTSYNC games, through Proton

Games like GTA V, Borderlands 3 or The Last of Us Part I talk to Logitech's lighting SDK. G502 Hub adds a small stand-in for it to that game's Proton prefix, so the game lights your mouse the way it does on Windows.

Safety

Built not to brick anything

  • Talks to the mouse over HID++ 2.0, the protocol G HUB uses, with no kernel driver and no root.
  • Backs up the whole onboard memory before the first change of a session, and every backup can be restored.
  • Writes only the user profile area, never the factory profiles, and reads every write back.
  • Keeps bytes it doesn't understand exactly as they were.

Install

One line. Then plug in the mouse.

$ curl -fsSL https://g502hub.ahmedxsaad.me/install.sh | sh

Installs what it needs with your package manager (it asks for your password), adds the permission rule that lets your user talk to the mouse, and puts G502 Hub in your applications menu. Remove it with the same line plus -s -- --uninstall.

$ yay -S g502-hub

For Arch, EndeavourOS, Manjaro and CachyOS. It builds the Proton bridge too, and updates with the rest of your system. See the package page.

$ git clone https://github.com/Ahmedxsaad/g502-hub && cd g502-hub
$ sudo install -m644 udev/70-g502-hub.rules /etc/udev/rules.d/
$ sudo udevadm control --reload && sudo udevadm trigger
$ python3 -m g502hub.gui

Needs Python 3.11+, PySide6 and numpy; the live effects also use GStreamer with PipeWire, PyGObject, dbus-fast and parec.

FAQ

Questions

Does it need Windows, Wine or G HUB?

No. G502 Hub is a native Linux app that talks to the mouse directly. Wine only comes in if you want Proton games to drive the lights.

Does anything leave my computer?

No. Screen and sound are analysed on your machine and never sent anywhere. The only download is the optional product photo of the mouse.

Will my settings work without the app?

Yes. DPI, buttons, report rate and the saved lighting live in the mouse's own memory, on Linux, Windows or a console. Live effects and rules need the app running, which it does quietly in the tray.

What about other G502 models?

Only the wired G502 HERO for now. If you have another G502 and want to help, open an issue with the info from the About page's "Copy for a bug report" button.

Macros?

Yes, two kinds. Saved on the mouse, a macro plays on any computer: keys, media keys, clicks, scrolling and waits. Run by G502 Hub, it can also type text in your keyboard layout, repeat while you hold the button, or toggle on and off. Record one by typing, or build it step by step.
